Основная идея нашего проекта - создать хоррор игру с видом сверху. Игрок будет проходить различные локации, попутно пытаясь не погибнуть от монстров. Локации, представленные комнатами, будут отличаться как задачей, которую необходимо выполнить, чтобы пройти дальше, так и наполнениемтак и монстрами. 

Стек проекта:
    Игровой движок - Godot
    Язык программирования - C++
    Контрольк версий -GitHub

Архитектура проекта: монолитная.
